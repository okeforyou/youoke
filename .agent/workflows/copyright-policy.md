# 🛑 YouOke Copyright Safe Harbor Policy (AI-Protocol)

นี่คือกฎเหล็ก (Core Directive) สำหรับ AI Agent ในการพัฒนาระบบ YouOke ทั้งหมด ห้ามละเมิดเด็ดขาด:

## 1. สถานะของ YouOke (Platform Identity)
* **YouOke คือ "เครื่องมือ (Tool)" และ "เครื่องเล่น (Player)" เท่านั้น**
* YouOke **ไม่ใช่** ผู้ให้บริการคอนเทนต์ (Content Provider) หรือแพลตฟอร์มแจกจ่ายไฟล์เพลง
* YouOke มีหน้าที่แค่อำนวยความสะดวกในการ **จัดคิวเพลง** และ **แยกเสียงผ่าน Local Machine** ของผู้ใช้เอง

## 2. สิทธิขาดของผู้ใช้งาน (User Rights)
* สิทธิ์ในการเข้าถึงเพลง เป็นสิทธิ์ที่ผู้ใช้ได้รับอยู่แล้วจาก YouTube (YouTube Terms of Service)
* การแยกเสียง (Demucs) เกิดขึ้นในฐานะ *การประมวลผลส่วนบุคคล (Fair Use/Personal Use)* ภายในเครื่องของผู้ใช้เอง
* ระบบจะต้องไม่ทำหน้าที่นำไฟล์ที่แยกเสียงแล้ว ไปกระจายสู่สาธารณะแบบ Public Download หรือศูนย์กลาง (Centralized File Hosting) โดยพลการ

## 3. หน้าที่ของ AI Agent (AI Developer Responsibility)
* **ห้าม** เสนอไอเดีย แผนงาน หรือเขียนโค้ดที่สุ่มเสี่ยงต่อการละเมิดลิขสิทธิ์ (เช่น การเขียนบอทไปดึงเพลงจากเซิร์ฟเวอร์เถื่อน, การฝังเพลงมีลิขสิทธิ์ไว้ใน Source Code, การทำระบบ Streaming เพลงแบบละเมิดสิทธิ์)
* หาก User มี Request ใดๆ ที่อาจนำไปสู่ความเสี่ยงด้านลิขสิทธิ์ **AI ต้องทำการ "แจ้งเตือน (Warn)" User ทันที** ก่อนดำเนินการใดๆ
* AI ต้องทำหน้าที่วิเคราะห์หาทางออก (Workaround) ที่ทำให้ระบบยังคงเป็นเพียง "เครื่องมือ" ที่ขาวสะอาด (เช่น การใช้ระบบ DRM ให้ Creator บริหารสิทธิ์เอง, การใช้ Token Base, การดึง Video ตรงจาก YouTube Player API)

> "อะไรที่จะขัดเกี่ยวกับเรื่องลิขสิทธิ์หรือสิทธิ์การใช้งาน ต้องแจ้งเตือนเราก่อน เพื่อหาทางไม่ให้โปรแกรมเราไปละเมิด" - *บันทึกตามคำสั่งของ User*
